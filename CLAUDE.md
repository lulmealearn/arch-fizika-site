# Сайт-визитка Arch / Физика — правила проекта

Репетитор по физике, студент МФТИ (ФЭФМ). Сайт: главная-визитка, выдвижная боковая панель, хранилище интерактивных визуализаций к урокам. Язык сайта — русский, тон живой и прямой, без канцелярита.

## Стек и запуск
- Статика без сборщиков: HTML + CSS + чистый JS. Никаких фреймворков без явной просьбы.
- Локально: `python -m http.server 8000` из корня репозитория (хранилище грузит JSON через fetch, с диска не работает).
- В перспективе свой сервер (nginx). Бэкенд позже, возможно MySQL для метаданных визуализаций; формат `data/visualizations.json` держать стабильным — API будет отдавать его же.

## Где что
- `source-viz/` — исходники визуализаций. Правки визуализаций только здесь.
- `viz/*.html` — сборка, руками не править. Пересобрать: `python tools/build_viz.py` (добавляет кнопку «← Все визуализации»).
- `data/visualizations.json` — порядок (= порядок в файле), названия, описание, раздел (один, цветной), теги (свободные), обложка.
- `assets/css/main.css` — токены дизайна и общие компоненты; `home.css`, `storage.css` — страницы.

## Дизайн «Лабораторный журнал»
- Бумага в клетку `#f7f6f2`, белые карточки, чернила `#181820`, акцент `#6d28d9`. Палитра общая с визуализациями.
- Шрифты: заголовки Jura (600–700), текст PT Serif, метки/чипы/кнопки JetBrains Mono капсом с разрядкой.
- Цвет раздела физики = цвет язычка папки и тега (см. `sections` в JSON).
- Анимации только transform/opacity, всё уважает `prefers-reduced-motion`. Контент не прячется в opacity:0 до скролла.
- Mobile-first: ученики открывают с телефона. Тач-цели ≥44px, без горизонтального скролла.
- Векторы над буквами рисовать линией (CSS/canvas), не символом U+20D7. Вместо ⏸/▶ — текстовые подписи.
