# Сайт-визитка Arch / Физика — правила проекта

Репетитор по физике, студент МФТИ (ФЭФМ). Сайт: главная-визитка, выдвижная боковая панель, хранилище интерактивных визуализаций к урокам, админка для их загрузки. Язык сайта — русский. Тон текстов — сдержанно-официальный, без сленга («домашка», «тапни») и без канцелярита. Владелец отверг и «машинный», и разговорный варианты. Исключение — приветствие на обложке, его текст задал сам владелец («Привет! Я Ахметьянов Артур Айдарович, репетитор с Физтеха…»).

## Стек и запуск
- Фронтенд: HTML + CSS + чистый JS в `public/`, без сборщиков и фреймворков без явной просьбы.
- Бэкенд: Python, FastAPI + SQLAlchemy 2, база SQLite (`storage/site.db`), на сервере планируется MySQL — код должен оставаться совместимым с обеими (никаких SQLite-специфичных фич).
- Запуск: `python run.py` (порт 8000), `--lan` для телефона, `python run.py set-password` для пароля админки.
- Владелец работает на Windows (PowerShell / Git Bash), Python 3.13. Синтаксис держать совместимым с Python 3.9 (Optional вместо `X | None`).

## Где что
- `public/` — единственное, что отдаётся как статика. Никогда не класть туда секреты и код бэкенда.
- `backend/app/` — маршруты: публичные в `routes_public.py`, админские в `routes_admin.py` (все под `require_admin`).
- `storage/` — база и загруженные файлы (`viz/`, `covers/`), в git не попадает.
- `seed/` — стартовые 8 визуализаций и разделы; импортируются только в пустую базу.
- Формат `/api/visualizations` = `{sections:[{id,label,color,tint,ink}], items:[{id,title,description,section,tags,parts,file,cover,access,locked}]}` — от него зависит `public/assets/js/storage.js`.
- Обложки в хранилище: загруженная через админку картинка, иначе иконка `public/assets/icons/viz/<slug>.svg`, иначе иконка раздела `_<раздел>.svg`. Иконки в манере Flaticon «lineal color»: предмет, толстый контур `#6d28d9`, плоская заливка `#c4b5fd`/`#ede9fe`, смещённая от контура; рисуются скриптом `tools/make_icons.py` (новую иконку добавлять туда же, в том же стиле).
- Визуализации отдаются с `CSP: sandbox` (без localStorage). Кнопка «← Все визуализации» добавляется при загрузке (`files.prepare_html`).

Баллистики больше нет. Визуализации и пробники в подарок не обещать — только план подготовки.
- Плавающая кнопка записи на телефоне: `.float-cta` + `[data-float-hide]` на блоках, где кнопка записи уже видна (логика в `main.js`).
- «Почему мне доверяют?»: `photo-trust.webp` — стикер владельца «в задумчивости» (сделан в ChatGPT по фото с обложки), вырезан из фона с белой обводкой. Отзывы на главной — дословно с Профи (ровно 6, сетка 3 × 2: верхний ряд — подробные Елена/Maria/Хава, обрезаны с «Читать полностью», нижний — короткие Оксана/Давид/Ника; разные годы; на планшете 2 колонки, на телефоне листаются вбок; месяц и год; стоимость работ не указывать; у всех оценка «5+» с Профи, показана как ★★★★★⁺).
- Шапка липкая (`.topbar`, подложка `.is-stuck` по скроллу): по желанию владельца при прокрутке вниз держится, при прокрутке вверх уезжает (`.is-hidden`, `html.topbar-hidden`); фильтры хранилища прилипают под ней (`--topbar-h`) и поднимаются, когда она спрятана. Меню: группа «На этой странице / Главная» со ссылками на блоки главной (#method, #about, #trust, #reviews, #free, #contacts) и группа «Страницы» (визуализации, стоимость, личный кабинет, интенсив).
- Лупы при наведении нет (владелец убрал); увеличение только по нажатию. Некликабельные карточки (цифры, «Как проходят занятия», «Варианты ЕГЭ», «Кураторы») статичны, без подъёма при наведении.
- Окна поверх страницы: `<dialog class="pop">` + кнопка `[data-pop="id"]`, логика в `public/assets/js/popup.js`. Кликабельные карточки отличаются чипом «Смотреть …» и реакцией на наведение; некликабельные не поднимаются при наведении.
- Карточка «Наука» на главной: заголовок «Моделирую плазму», в тексте без «0D» (владелец упростил).
- Анимации только transform/opacity, всё уважает `prefers-reduced-motion`. Контент не прячется в opacity:0 до скролла.
- Mobile-first: ученики открывают с телефона. Тач-цели ≥44px, без горизонтального скролла.
- Векторы над буквами рисовать линией (CSS/canvas), не символом U+20D7. Вместо ⏸/▶ — текстовые подписи.

## Ученики и доступ
- Регистрация в личном кабинете `public/account/` (ник + пароль, больше ничего не храним; ник без учёта регистра; пароль ≥ 6). Восстановления по почте нет — новый пароль задаёт админ (вкладка «Ученики»), старые сессии ученика сбрасываются (`users.session_version`).
- **Занятие = папка ученика** (решение владельца): номер, тема, ссылка на запись (Телебосс/VK, может быть пустой), конспект и ДЗ в PDF (`lessons.notes_file`/`hw_file`, файлы в `storage/hw/`), визуализации (`lesson_viz`, по порядку). Отдельных «Домашек» и «Уроков» больше нет: старые ДЗ при запуске переносятся в занятие с тем же номером (`seed._migrate_homeworks`).
- Доступ выдаётся **вручную каждому ученику**: `grants` (kind = `lesson` или `viz`). Открытое занятие открывает всё в папке, включая закрытые визуализации (`access.opened_viz_ids`); `viz` — отдельная закрытая визуализация без занятия. Отметки «ученик» нет.
- Визуализация: `access` = `free` (всем без входа) или `private`. Закрытые видны в хранилище с замком и ведут в кабинет. Владелец хочет оставить бесплатными около 15.
- PDF: `/hw/<номер>` и `/notes/<номер>` — только тем, кому открыто занятие; без доступа редирект в `/account/?next=…` (с `locked=1`, если вошёл).
- Кабинет: поиск по номеру или теме (Enter открывает единственное совпадение), фильтр «Все / Не просмотрены / Просмотрены», папки-карточки; окно папки `<dialog id="lesson">`, ссылка `/account/#z12` открывает занятие 12. Цвет папки: **красная — не просмотрено (по умолчанию), зелёная — просмотрено**, ученик переключает сам (`lesson_progress`, `PUT /api/me/progress/<id>`). Красный/зелёный — исключение из фиолетовой палитры по просьбе владельца.
- Админ в том же браузере видит всё: `/api/auth/me` и `/api/visualizations` отдают `admin`, хранилище и кабинет показывают тёмную плашку «открыта админка» с кнопкой выхода (владелец принял это за поломку приватности).
- Код: `access.py`, `routes_auth.py` (регистрация, вход, `/api/me/materials`, прогресс), `routes_admin_access.py` (ученики, доступы, занятия), фронт `account.js`, `admin-access.js`. Все PDF (конспекты, ДЗ, пробники, решения, отчёты) лежат в `storage/hw/`, имя с хешем содержимого. Cookie ученика `user_session` (SameSite=Lax, чтобы ссылки из Telegram открывались с входом), POST — с проверкой Origin.
- Новые колонки в существующих таблицах добавлять в `seed.NEW_COLUMNS` (create_all их не создаёт).
- Кабинет разделён вкладками «Занятия · Пробники · Отчёты» (`#probniki`, `#otchety` в адресе открывают вкладку).
- **Пробники** (`mocks`): номер, название и вариант. **Решений нет** (решение владельца; колонка `solutions_file` не используется). Владелец делает пробники **в HTML**: они отдаются как визуализации (CSP sandbox, без localStorage) с кнопкой «← В личный кабинет» (`files.MOCK_BACKLINK` → `/account/#probniki`); PDF тоже принимается; к занятиям не привязаны; доступ вручную (`grants.kind = mock`); ученик отмечает «решён» (красный → зелёный, `mock_progress`). Адрес `/mock/<номер>`. Баллов и графика нет — владелец отказался.
- **Отчёты** (`reports`): личный PDF ученика с аналитикой за период, админ загружает раз в месяц (вкладка «Ученики» → «Отчёты», период по умолчанию — прошлый месяц до 15-го числа). Видит только сам ученик и админ (`/report/<id>`). Отдельной ссылки для родителей нет — смотрят через аккаунт ученика (решение владельца).
- **Активность учеников** (`tracking.py`): сеансы `visits` (перерыв > 30 мин — новый сеанс; устройство — только «Android · Chrome», без IP), открытые материалы `views` (запись, конспект, ДЗ, визуализация, пробник, отчёт; повтор того же в течение 10 мин не пишется). Запись урока открывается через `/watch/<номер>` (проверка доступа + учёт + редирект на Телебосс). Кабинет раз в минуту шлёт `POST /api/me/ping`, пока виден. Действия в браузере, где открыта админка, не учитываются. Журнал старше года чистится при запуске.
- Админка → «Ученики»: в строке — когда заходил, сеансов и устройств за 30 дней (3+ устройства подсвечены красным как возможный общий аккаунт), полоски «Занятия просмотрены» и «Пробники решены»; кнопка «Подробнее» (`GET /api/admin/users/<id>/activity`) — плитки, прогресс по каждому занятию и пробнику, сеансы, что открывал.
- Время в API всегда с часовым поясом (`serialize._iso`): SQLite отдаёт его без пояса, хранится UTC.
- В планах (не делать без согласования): лимит устройств на аккаунт, водяной знак с ником в закрытых визуализациях.

- Статика (страницы, CSS, JS) отдаётся с `Cache-Control: no-cache` (middleware в `main.py`), чтобы после обновления браузер не держал старые файлы.
