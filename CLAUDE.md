# Сайт-визитка Arch / Физика — правила проекта

Репетитор по физике, студент МФТИ (ФЭФМ). Сайт: главная-визитка, выдвижная боковая панель, хранилище интерактивных визуализаций к урокам, админка для их загрузки. Язык сайта — русский. Тон текстов — сдержанно-официальный, без сленга («домашка», «тапни») и без канцелярита. Владелец отверг и «машинный», и разговорный варианты. Исключение — приветствие на обложке, его текст задал сам владелец («Привет! Я Ахметьянов Артур Айдарович, репетитор с Физтеха…»).

## Стек и запуск
- Фронтенд: HTML + CSS + чистый JS в `public/`, без сборщиков и фреймворков без явной просьбы.
- Бэкенд: Python, FastAPI + SQLAlchemy 2, база SQLite (`storage/site.db`), на сервере планируется MySQL — код должен оставаться совместимым с обеими (никаких SQLite-специфичных фич).
- Запуск: `python run.py` (порт 8000), `--lan` для телефона, `python run.py set-password` для пароля админки.
- Владелец работает на Windows (PowerShell / Git Bash), Python 3.13. Синтаксис держать совместимым с Python 3.9 (Optional вместо `X | None`).

## Где что
- `public/` — единственное, что отдаётся как статика. Никогда не класть туда секреты и код бэкенда.
- `backend/app/` — маршруты: публичные в `routes_public.py`, админские в `routes_admin.py` (все под `require_admin`).
- `storage/` — база и загруженные файлы (`viz/`, `covers/`), в git не попадает.
- `seed/` — стартовые 8 визуализаций и разделы; импортируются только в пустую базу.
- Формат `/api/visualizations` = `{sections:[{id,label,color,tint,ink}], items:[{id,title,description,section,tags,parts,file,cover}]}` — от него зависит `public/assets/js/storage.js`.
- Обложки в хранилище: загруженная через админку картинка, иначе иконка `public/assets/icons/viz/<slug>.svg`, иначе иконка раздела `_<раздел>.svg`. Иконки в манере Flaticon «lineal color»: предмет, толстый контур `#6d28d9`, плоская заливка `#c4b5fd`/`#ede9fe`, смещённая от контура; рисуются скриптом `tools/make_icons.py` (новую иконку добавлять туда же, в том же стиле).
- Визуализации отдаются с `CSP: sandbox` (без localStorage). Кнопка «← Все визуализации» добавляется при загрузке (`files.prepare_html`).

## Дизайн «Лабораторный журнал»
- Бумага в клетку `#f7f6f2`, белые карточки, чернила `#181820`, акцент `#6d28d9`. Палитра общая с визуализациями.
- Шрифты: заголовки Jura (600–700), текст PT Serif, метки/чипы/кнопки JetBrains Mono капсом с разрядкой.
- Цвет раздела физики = цвет язычка папки и тега (таблица `sections`). Разделы: Математика, Механика, МКТ и термодинамика, Электродинамика, Оптика, Кванты — источник правды `seed/visualizations.json`, синхронизируются при запуске (`seed._sync_sections`, старые slug'и переезжают по `SECTION_REMAP`). Фильтр в хранилище только по разделу.
- Главная собрана в стиле карточек владельца с Профи: фиолетовая обложка с формулами, чёрные/белые плашки-заголовки (`.banner`, `.plate`), маркеры-выделения (`.mark--*`), фото-вырезки из `public/assets/img/`. Бирюзовый не использовать — владелец выбрал фиолетовый.
- Реальные факты: Ахметьянов Артур Айдарович; ЕГЭ по физике 97 (2023); 600+ занятий; 3+ года; 4,83 по 23 отзывам на Профи; призёр и победитель перечневых олимпиад по физике (дипломы в `public/assets/img/diploma-*.webp`, открываются окном `#pop-olymp`); бакалавриат МФТИ ФЭФМ (фото с группой — окно `#pop-fefm`). Кураторов без числа. Цены — отдельная страница `public/prices/index.html` (как хранилище): карточка-«дуэль» «Самостоятельно ✕ / Занятия со мной ✓» с общим графиком на одних осях (серая — хаотичные всплески мотивации с разной амплитудой и пунктирный веер исходов с «?»; фиолетовая — рост с малыми колебаниями к «ЕГЭ 90+» через этапы «план подготовки → разбор ошибок → пробные варианты»; на телефоне отдельный упрощённый график). SVG генерирует `tools/make_duel_chart.py`, проявление — clipPath `.duel__clip` по `[data-draw]`, фиолетовая карточка группы 1500 ₽/час с плашкой «Ближайший набор в группу: [дата]» и стикером «Первое занятие бесплатно», ниже обычная карточка «Индивидуальные занятия — от 3500 ₽/час, по договорённости» (без записей и дорешек), в конце тёмный блок бесплатного занятия, устроенный как на главной (текст | билет, три шага в линию). Саммари нигде не упоминать — их нет. Главная ссылается на цены из меню и из блока «Бесплатное занятие».
- Блок «Бесплатное занятие»: на главной фиолетовый с белым билетом (фиолетовая карта плана) — не менять; на странице цен чёрный `.free--dark` с золотым билетом `.ticket--gold` и чёрно-золотой картой плана.
- Блок «Бесплатное занятие» на главной: «билет» на пробное (0 ₽ вместо 1500 ₽, корешок «план подготовки в подарок»; в списке бесплатного урока 3 пункта, последний — персональный план в подарок), весь билет — ссылка на бота (отдельной кнопки бота и ссылки на Профи в этом блоке нет). Баллистики больше нет. Визуализации и пробники в подарок не обещать — только план подготовки.
- Плавающая кнопка записи на телефоне: `.float-cta` + `[data-float-hide]` на блоках, где кнопка записи уже видна (логика в `main.js`).
- «Почему мне доверяют?»: `photo-trust.webp` — стикер владельца «в задумчивости» (сделан в ChatGPT по фото с обложки), вырезан из фона с белой обводкой. Отзывы на главной — дословно с Профи (ровно 6 за разные годы и про разное — Елена, Оксана, Хава, Павел, Maria, Ника; на компе три колонки `.reviews__col` по паре с выровненным низом; месяц и год; стоимость работ не указывать; у всех оценка «5+» с Профи, показана как ★★★★★⁺).
- Шапка липкая (`.topbar`, подложка `.is-stuck` по скроллу): по желанию владельца при прокрутке вниз держится, при прокрутке вверх уезжает (`.is-hidden`, `html.topbar-hidden`); фильтры хранилища прилипают под ней (`--topbar-h`) и поднимаются, когда она спрятана. Меню: группа «На этой странице / Главная» со ссылками на блоки главной (#method, #about, #trust, #reviews, #free, #contacts) и группа «Страницы» (визуализации, цены, интенсив).
- Лупы при наведении нет (владелец убрал); увеличение только по нажатию. Некликабельные карточки (цифры, «Как проходят занятия», «Варианты ЕГЭ», «Кураторы») статичны, без подъёма при наведении.
- Окна поверх страницы: `<dialog class="pop">` + кнопка `[data-pop="id"]`, логика в `public/assets/js/popup.js`. Кликабельные карточки отличаются чипом «Смотреть …» и реакцией на наведение; некликабельные не поднимаются при наведении.
- Анимации только transform/opacity, всё уважает `prefers-reduced-motion`. Контент не прячется в opacity:0 до скролла.
- Mobile-first: ученики открывают с телефона. Тач-цели ≥44px, без горизонтального скролла.
- Векторы над буквами рисовать линией (CSS/canvas), не символом U+20D7. Вместо ⏸/▶ — текстовые подписи.

- Статика (страницы, CSS, JS) отдаётся с `Cache-Control: no-cache` (middleware в `main.py`), чтобы после обновления браузер не держал старые файлы.
