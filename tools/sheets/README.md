# Связь сайта с Google-таблицей

Таблица «Ученики — учёт занятий» остаётся главным хранилищем. Сайт:

- **пишет в неё** сданные ДЗ, а после проверки куратором — «Верных», «Всего» и «Комментарий к ДЗ». Строка выбирается по теме урока. Пробники пишутся в столбец с номером пробника на вкладке «П-…»: первая часть — сразу после сдачи, вторая — после проверки.
- **берёт из неё** занятия, ответы на опросы бота и пробники для ежемесячных отчётов. 1-го числа сайт сам собирает черновики за прошлый месяц. Вы их проверяете, дописываете комментарий и публикуете.

Сайт не трогает формулы и не удаляет строки. Он пишет только в столбцы «ДЗ сдал», «Дата сдачи», «Верных», «Всего» и «Комментарий к ДЗ», а на вкладке «П-…» — дату и баллы по заданиям.

Связь идёт через отдельный скрипт Apps Script — `site.gs`. Google Cloud и ключи не нужны.

## Установка (один раз, минут 10)

1. Откройте https://script.google.com и нажмите **«Новый проект»**. Это должен быть отдельный проект, не тот, где живёт бот: у скрипта сайта своя функция `doPost`, и она не должна мешать боту. Назовите проект, например, «Сайт ↔ таблица».
2. Удалите всё в файле `Code.gs` и вставьте целиком содержимое `tools/sheets/site.gs`.
3. Остановите сайт и выполните в папке сайта:
   ```
   python run.py set-sheet
   ```
   Команда покажет **секрет**. Вставьте его в строку `const SECRET = '…'` в скрипте и сохраните (Ctrl+S). Адрес команда спросит на шаге 6, а пока окно можно оставить открытым.
   `SHEET_ID` уже вписан — это id вашей таблицы из её адреса.
4. В редакторе выберите функцию **`testAccess`** и нажмите **▶ Выполнить**. Google попросит доступ к таблицам: «Проверить разрешения» → ваш аккаунт → «Дополнительные настройки» → «Перейти к проекту» → «Разрешить». В журнале появится название таблицы.
5. **Развернуть → Новое развертывание** → шестерёнка → **«Веб-приложение»**:
   - «Запуск от имени»: **Я**;
   - «У кого есть доступ»: **Все**. Без этого сайт не достучится; чужие без секрета ничего не получат.
   Нажмите «Развернуть» и скопируйте **URL веб-приложения**, он заканчивается на `/exec`.
6. Вставьте этот адрес в окно `python run.py set-sheet`. Если окно уже закрыто, запустите команду ещё раз: секрет останется тем же.
7. Запустите сайт. Откройте админку → «Ученики» → **«Таблица»**: там должна быть надпись «Связь есть» и список вкладок.

## Как сайт находит ученика

- По **chat id**. В первой строке вкладки ученика уже записан его `chat_id:`. На сайте тот же chat id вписывается ученику в админке («Ученики» → «Telegram»).
- Если на вкладке chat id нет (например, «Тест»), укажите вкладку вручную в том же окне: поле «Вкладка в Google-таблице».
- Окно «Таблица» показывает, кто к какой вкладке привязан и кто остался без вкладки.

## Как сайт находит строку ДЗ

По **теме урока**. Название занятия на сайте должно совпадать с «Темой урока», которую бот пишет в таблицу. Регистр, «ё» и знаки препинания не важны. Если одна тема целиком входит в другую, это тоже совпадение.

Если строки нет, работа всё равно сдаётся и проверяется. На странице проверки появится пометка «в таблицу не записано: нет строки с темой …» и кнопка **«Записать ещё раз»**: исправьте тему в таблице или в занятии и нажмите её.

## Если поменяли скрипт

«Развернуть» → «Управление развертываниями» → карандаш → «Версия: новая» → «Развернуть». Адрес не меняется, на сайте ничего делать не нужно.

## Если что-то не работает

| Что видно | Что сделать |
|---|---|
| «Неверный секрет» | Секрет в скрипте должен совпадать с `SHEETS_SECRET` в `.env` сайта. |
| «Google не пустил к скрипту» / «пришла страница Google» | Разверните заново с доступом «Все» и запуском «от имени: я». Один раз запустите `testAccess`. |
| «Ни на одной вкладке нет chat_id …» | Впишите chat id в первую строку вкладки ученика рядом с `chat_id:` или укажите вкладку на сайте. |
| «столбцы только для пробников 1–40» | На вкладке «П-…» 40 столбцов. Пробник с номером больше 40 нужно перенумеровать. Другой вариант — добавить столбцы и увеличить `MOCK_COUNT` в скрипте. |
