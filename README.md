# Arch / Физика — сайт-визитка

Статический сайт без сборщиков и фреймворков: HTML, CSS, чистый JS.
Разворачивается на любом сервере как папка со статикой.

## Структура

```
index.html                 главная
viz/index.html             хранилище визуализаций
viz/*.html                 сами визуализации (собираются скриптом, руками не править)
source-viz/*.html          исходники визуализаций — правь здесь
data/visualizations.json   список визуализаций: порядок, названия, разделы, теги, обложки
covers/                    обложки (пока пусто)
assets/css/main.css        токены дизайна, кнопки, шапка, боковая панель
assets/css/home.css        стили главной
assets/css/storage.css     стили хранилища
assets/js/main.js          боковая панель и появление блоков при скролле
assets/js/home.js          бросок в рамке под фото и мини-график
assets/js/storage.js       рендер хранилища и фильтры
tools/build_viz.py         копирует source-viz → viz и добавляет кнопку «← Все визуализации»
```

## Запуск локально

Хранилище читает JSON через `fetch`, поэтому с диска двойным кликом не откроется. Нужен любой локальный сервер:

```
cd site
python3 -m http.server 8000
```

и открыть http://localhost:8000

## Как добавить визуализацию

1. Положить файл в `source-viz/` с именем латиницей, например `impuls.html`.
2. Добавить запись в `data/visualizations.json` в нужное место списка (порядок в файле = порядок на сайте):

```json
{
  "id": "impuls",
  "title": "Закон сохранения импульса",
  "description": "Что внутри, одним-двумя предложениями.",
  "section": "dinamika",
  "tags": ["ЕГЭ", "задачи"],
  "parts": "8 разделов",
  "file": "impuls.html",
  "cover": null
}
```

3. Запустить `python3 tools/build_viz.py`.

Раздел (`section`) — один, цветной, из списка `sections` в том же JSON. Теги — сколько угодно, свободные.
Раздел появляется в фильтрах автоматически, как только в нём есть хотя бы одна визуализация.

## Обложки

Положить картинку в `covers/` (лучше SVG или WebP, соотношение примерно 3:2) и прописать `"cover": "covers/impuls.svg"`.
Пока `cover` равен `null`, в папке показывается заглушка.

## Фото на главной

В `index.html` найти комментарий у `<canvas id="throw">` и заменить canvas с подписью на
`<img src="assets/img/photo.jpg" alt="...">`. Стили рамки уже готовы.

## Деплой на свой сервер

Достаточно отдать папку как статику, например nginx:

```
server {
    listen 80;
    server_name example.ru;
    root /var/www/site;
    index index.html;
    location / { try_files $uri $uri/ =404; }
}
```

## Бэкенд (позже)

Страница хранилища зависит только от формата JSON. Когда появится сервер с MySQL, достаточно отдавать
тот же формат по адресу, например `/api/visualizations`, и поменять одну строку `DATA_URL` в `assets/js/storage.js`.
Сами HTML-файлы визуализаций лучше оставить на диске и отдавать nginx, а в базе хранить только метаданные.
