Конденсатор в электрических цепях

Ёмкость, энергия, соединения и главное — как конденсатор ведёт себя в цепи: заряжается, разряжается и в итоге перестаёт пропускать ток. Цвет провода везде показывает потенциал: синий — ноль, красный — «+» источника.

Ёмкость: сколько заряда на один вольт

Две пластины, между ними диэлектрик. Меняйте площадь, зазор и диэлектрик и смотрите справа, во сколько раз изменились ёмкость, заряд, напряжение и поле. Потом отключите источник — картина поменяется.

C = 44,3 пФ q = 0,443 нКл U = 10,0 В E = 5,00 кВ/м
—
C = q / U C = εε₀S / d U = E·d E = 2·Eпластины [C] = Ф
Откуда 2Eпластины

Каждая пластина создаёт поле по обе стороны от себя. Между пластинами поля «+» и «−» смотрят в одну сторону и складываются, снаружи смотрят навстречу и гасятся. Нажмите «поле каждой пластины».

Не путай

Ёмкость зависит только от S, d и ε. Формула C = q/U её измеряет, но не задаёт: удвоили U — удвоился q, а C та же.

Энергия: площадь под графиком U(q)

Заряд переносится маленькими порциями dq. Каждая порция идёт против уже накопленного напряжения U = q/C, поэтому стоит дороже предыдущей. Сумма всех порций — площадь треугольника.

q = 0 мкКл U = 0 В W = qU/2 = 0 мкДж
W = CU²/2 = qU/2 = q²/2C W = ∫U dq = площадь треугольника
Почему половина

Первая порция переносится почти при нуле, последняя — при полном U. В среднем порции «видят» U/2, поэтому W = q·U/2, а не q·U.

Последовательное и параллельное соединение

Скачок цвета на конденсаторе — это напряжение на нём. При последовательном соединении напряжение делится, при параллельном — одно на всех.

CΣ = — мкФ q₁ = —, q₂ = — мкКл U₁ = —, U₂ = — В
—
последовательно: q₁ = q₂,  1/CΣ = 1/C₁ + 1/C₂ параллельно: U₁ = U₂,  CΣ = C₁ + C₂
Когда q₁ = q₂

Внутренние пластины и провод между ними (в пунктирной рамке) — изолированный кусок металла. Если до подключения он был не заряжен, его заряд так и остаётся нулём: −q₁ + q₂ = 0. Для заранее заряженных конденсаторов это не работает.

Зарядка через резистор

Замыкаем ключ. Сначала пустой конденсатор пропускает ток как провод. Заряд растёт, напряжение на C растёт, на резистор остаётся всё меньше — и ток затухает. Точки — направление тока.

t = — q = — мКл I = — мА τ = RC = — с
—
ε = UC + UR = q/C + R·dq/dt q(t) = Cε(1 − e−t/RC) I(t) = (ε/R)·e−t/RC τ = RC
Как читать τ

Пунктирная касательная к q(t) доходит до Cε ровно при t = τ. На деле за τ набирается 63 % заряда, за 3τ — 95 %, за 5τ — больше 99 %.

Куда уходит половина энергии

Источник совершает работу qε = Cε², а в конденсаторе остаётся Cε²/2. Вторая половина выделяется теплом в резисторе — при любом R.

Разрядка: вся энергия уходит в тепло

Заряженный конденсатор замыкаем на резистор. Ток идёт от «+» пластины через R к «−», пока заряды не уравняются. Источника нет, поэтому вся энергия конденсатора становится теплом.

t = — q = — мКл WC = — мДж Q = — мДж
—
I·R = q/C,  −R·dq/dt = q/C q(t) = q₀·e−t/RC ЗСЭ: WC = CU²/2 = Q
Закон сохранения энергии

Полоски под схемой: энергия конденсатора убывает, тепло растёт, а их сумма не меняется. В конце Q = CU₀²/2.

Установившийся режим: конденсатор — разрыв

Через несколько τ заряд перестаёт меняться: q = const, значит IC = 0. Ток через конденсатор не идёт, а напряжение на нём равно напряжению на параллельном участке. Задача №0 из конспекта.

I = — А IR = — А IC = — А UC = — В
—
ток источникаток через Rток в конденсатор
IC = 0 I = ε / (R + r) UC = UR = εR / (R + r) q = CεR / (R + r)
Два правила

В первый момент пустой конденсатор — провод: UC = 0, весь ток идёт в него. В установившемся режиме — разрыв: IC = 0. Вычеркните ветку с C и считайте цепь без неё.

Задачи из конспекта

Общий метод: в установившемся режиме вычеркнуть ветки с конденсаторами, найти токи, затем потенциалы. Напряжение на C — разность потенциалов его обкладок.

Ключ K замкнут, ε = 12 В, C = 0,2 мкФ. После размыкания ключа на резисторе выделилось Q = 10 мкДж. Найдите r/R. (Демидова, 2019)

UC = εR/(R+r) = — В Q = CUC²/2 = — мкДж
—
(C/2)·(εR/(R+r))² = Q r/R = ε·√(C/2Q) − 1 = 12·0,1 − 1 = 0,2
Поправка к конспекту

При переходе ко второй строке потерян множитель ε². Верно: R²/(R+r)² = 2Q/(Cε²). Без ε получилось бы r/R = −0,9, а под корнем стояла бы размерная величина 1/В².

Какие заряды установятся на конденсаторах через длительное время после замыкания ключа?

qC = —·Cε q2C = —·Cε
—
до: CΣ = 2C/3,  qC = q2C = 2Cε/3 после: q2C = 0,  qC = Cε
Почему так

В установившемся режиме через C тока нет, значит нет его и через R: UR = 0. Конденсатор 2C подключён параллельно R, поэтому U2C = 0. Всё напряжение ε остаётся на C.

Дано C, ε, R. Найти заряд конденсатора в установившемся режиме.

φ = 20ε/29 = — В φ* = 12ε/29 = — В UC = ε − φ* = — В
потенциал: 0 → ε× ветка без тока
I₀ = (ε − φ)/R = I₁ + I₂ = φ/4R + φ*/3R φ*/3R = (φ − φ*)/2R → φ* = 3φ/5 qC = C(ε − φ*) = 17Cε/29
Проверка

При ε = 29 В: φ = 20 В, φ* = 12 В, UC = 17 В. Токи в долях ε/29R: 9 = 5 + 4 — в узле всё сходится.

Три вещи, которые решают половину задач

1. Пустой конденсатор в первый момент — провод, в установившемся режиме — разрыв.

2. Напряжение на C — разность потенциалов его обкладок; ищите её методом потенциалов.

3. При разрядке энергия CU²/2 целиком уходит в тепло; при зарядке в тепло уходит столько же, сколько остаётся в C.

Самые дорогие ошибки
  • Пускать ток через конденсатор в установившемся режиме.
  • Писать q₁ = q₂ для заранее заряженных конденсаторов.
  • Терять множители при возведении в квадрат — проверяйте ответ размерностью.
